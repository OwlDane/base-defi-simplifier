# Base DeFi Simplifier

A hackathon project for Base Track that simplifies DeFi experience on Base L2.

## Tech Stack

- **Frontend**: Next.js 16 + TypeScript + OnchainKit
- **Backend**: Golang + Fiber
- **Database**: Supabase
- **Blockchain**: Base L2

## Features

- Lightning fast transactions on Base L2
- Secure wallet integration with OnchainKit
- Simplified token swapping interface
- Real-time portfolio tracking
- Liquidity pool management
